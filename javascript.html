Variáveis e tipos

const

O que é: a palavra que cria uma variável cujo valor não pode ser trocado depois.

Para que serve: guardar um valor que não muda, como o elemento que você pegou da página.

Quando usar: por padrão, sempre que o valor não precisar mudar. É a escolha mais segura.

Exemplo

const nome = "Luiz";
const numero = document.getElementById("numero");

let

O que é: a palavra que cria uma variável cujo valor pode ser trocado depois.

Para que serve: guardar valores que mudam ao longo do programa, como o contador do seu portfólio.

Quando usar: só quando o valor precisar mudar. Se não for mudar, use const.

Exemplo

let contador = 0;
contador++;

Tipos de dados

O que é: as categorias de valor que o JavaScript conhece. Os principais são texto (string), número (number) e verdadeiro ou falso (boolean).

Para que serve: cada tipo se comporta de um jeito. Números somam, textos se juntam, e booleanos alimentam as decisões do if.

Quando usar: o texto vai entre aspas, o número vai sem aspas, e o booleano é escrito como true ou false.

Exemplo

const texto = "Olá";
const idade = 30;
const ativo = true;

Decisões e repetições

if e else

O que é: a estrutura de decisão. O if executa um bloco só se a condição for verdadeira, e o else executa outro bloco quando ela é falsa.

Para que serve: fazer o programa escolher o que fazer, como mudar a cor do contador quando passa de 10.

Quando usar: sempre que o resultado depender de uma condição. A condição vai entre parênteses, e o bloco vai entre chaves.

Exemplo

if (contador > 10) {
numero.style.color = "red";
} else {
numero.style.color = "";
}

Operadores de comparação

O que é: os símbolos que comparam dois valores e devolvem verdadeiro ou falso.

Para que serve: montar as condições do if.

Quando usar: o === compara se são iguais, o !== compara se são diferentes, e os símbolos >, <, >= e <= comparam tamanhos. Prefira o === ao ==, porque ele também confere o tipo do valor.

Exemplo

texto === ""
idade >= 18
nome !== "Luiz"

Operadores lógicos

O que é: os símbolos que combinam condições: && significa "e", || significa "ou", e ! inverte o resultado.

Para que serve: testar mais de uma condição ao mesmo tempo.

Quando usar: o && exige que as duas sejam verdadeiras, e o || basta que uma seja.

Exemplo

if (idade >= 18 && ativo) {
console.log("Pode entrar");
}

for

O que é: o laço de repetição com contagem. Ele tem três partes: onde começa, até quando continua e como avança.

Para que serve: repetir uma tarefa um número de vezes conhecido, como percorrer uma lista de itens.

Quando usar: quando você sabe quantas vezes quer repetir. O i++ soma 1 a cada volta.

Exemplo

for (let i = 0; i < 3; i++) {
console.log("Volta " + i);
}

while

O que é: o laço de repetição que continua enquanto uma condição for verdadeira.

Para que serve: repetir uma tarefa sem saber de antemão quantas vezes.

Quando usar: quando a repetição depende de uma condição. Cuidado: se a condição nunca ficar falsa, o laço nunca termina e trava a página.

Exemplo

let numero = 3;
while (numero > 0) {
numero--;
}

Funções e eventos

function

O que é: um bloco de código com nome, que você escreve uma vez e pode executar quantas vezes quiser.

Para que serve: reaproveitar código e organizar o programa em partes pequenas, cada uma com uma tarefa.

Quando usar: sempre que uma tarefa se repetir. Os valores que a função recebe ficam entre parênteses e se chamam parâmetros. O return devolve o resultado.

Exemplo

function somar(a, b) {
  return a + b;
}

const total = somar(2, 3);

Função de seta

O que é: uma forma mais curta de escrever uma função, usando o símbolo =>.

Para que serve: escrever funções pequenas, principalmente as que são entregues a outras funções, como nos eventos.

Quando usar: em funções curtas e nos eventos de clique. Foi a forma que você usou no contador do portfólio.

Exemplo

const dobro = (n) => {
  return n * 2;
};

addEventListener

O que é: o comando que fica "escutando" um evento de um elemento, como um clique, e executa uma função quando ele acontece.

Para que serve: fazer a página reagir ao visitante, como somar no contador ao clicar no botão.

Quando usar: sempre que algo precisar acontecer em resposta a uma ação. Ele recebe dois valores: o nome do evento e a função a executar.

Exemplo

botaoSomar.addEventListener("click", () => {
  contador++;
  numero.textContent = contador;
});

Eventos mais comuns

O que é: os nomes das ações que o navegador reconhece e avisa ao JavaScript.

Para que serve: escolher o momento certo para reagir.

Quando usar: o click reage ao clique. O input reage a cada tecla digitada num campo. O submit reage ao envio de um formulário. O mouseover reage ao mouse passando por cima.

Exemplo

campo.addEventListener("input", () => {
  console.log(campo.value);
});

console.log

O que é: o comando que escreve uma mensagem no Console do navegador.

Para que serve: descobrir o que o programa está fazendo e achar erros. Você usou o Console para investigar o botão de voltar ao topo.

Quando usar: durante o desenvolvimento. O Console abre com F12. Depois, tire as mensagens, para não poluir a página.

Exemplo

console.log("Contador:", contador);

DOM: mexendo na página

O que é o DOM

O que é: a sigla de Document Object Model. É a versão da sua página que o navegador monta na memória, como uma árvore de elementos que o JavaScript consegue ler e mudar.

Para que serve: permitir que o JavaScript encontre elementos, troque textos e estilos, crie e remova partes da página, sem precisar recarregá-la.

Quando usar: sempre que a página precisar reagir ao visitante. O ponto de entrada é o objeto document.

Exemplo

console.log(document.title);

getElementById

O que é: o comando que encontra um elemento da página pelo seu id.

Para que serve: pegar um elemento para guardar numa variável e mexer nele depois.

Quando usar: quando o elemento tem um id. Se o id não existir, o resultado é null, e o código seguinte dá erro.

Exemplo

const numero = document.getElementById("numero");

querySelector

O que é: o comando que encontra o primeiro elemento que combina com um seletor de CSS.

Para que serve: pegar elementos por classe, tag ou qualquer seletor, com a mesma escrita do CSS.

Quando usar: quando não há id. Para pegar todos os elementos que combinam, use o querySelectorAll.

Exemplo

const titulo = document.querySelector("h1");
const cartoes = document.querySelectorAll(".cartao");

textContent

O que é: a propriedade que lê ou troca o texto de um elemento.

Para que serve: mudar o que aparece na tela, como o número do contador.

Quando usar: para textos simples. Ela trata tudo como texto, e não como HTML, o que é mais seguro do que innerHTML.

Exemplo

numero.textContent = 5;

style

O que é: a propriedade que muda o estilo de um elemento direto pelo JavaScript.

Para que serve: trocar cores, tamanhos e visibilidade em resposta a um evento, como o contador ficando vermelho acima de 10.

Quando usar: para mudanças pontuais. As propriedades de CSS com hífen viram escritas juntas, com a segunda palavra maiúscula, como backgroundColor. Para vários estilos, é mais organizado trocar a classe.

Exemplo

numero.style.color = "red";
numero.style.backgroundColor = "yellow";

classList

O que é: a propriedade que adiciona, remove ou alterna classes CSS de um elemento.

Para que serve: mudar o visual por inteiro, deixando o estilo no arquivo CSS e o JavaScript só decidindo quando aplicar.

Quando usar: o add acrescenta uma classe, o remove tira, e o toggle liga e desliga, como o riscar e desriscar das tarefas.

Exemplo

item.classList.toggle("feito");

createElement e appendChild

O que é: o createElement cria um elemento novo na memória, e o appendChild o coloca dentro de outro elemento, na página.

Para que serve: acrescentar partes à página sem escrevê-las no HTML, como cada tarefa da sua lista.

Quando usar: quando o conteúdo depende do visitante ou de dados. O elemento criado só aparece depois do appendChild.

Exemplo

const item = document.createElement("li");
item.textContent = "Estudar JavaScript";
lista.appendChild(item);

value

O que é: a propriedade que lê ou troca o conteúdo de um campo de formulário.

Para que serve: pegar o que o visitante digitou, ou limpar o campo depois de usar.

Quando usar: em campos input. O resultado é sempre um texto, mesmo quando o visitante digita um número. O trim() tira os espaços do começo e do fim.

Exemplo

const texto = campo.value.trim();
campo.value = "";

Bem-vindo à Biblioteca Front-end

Um dicionário de HTML, CSS e JavaScript feito para estudar e consultar. Cada comando tem o que é, para que serve, quando usar e um exemplo.

Como usar

  1. Escolha uma área no sumário abaixo, ou no menu do topo.
  2. Use o índice no começo de cada página para ir direto à categoria.
  3. Leia o verbete e compare o exemplo com o resultado, quando houver.
  4. Use o botão ↑ no canto da tela para voltar ao topo.

Sumário

  • HTML

    As tags que montam a estrutura da página: estrutura, textos, links, imagens, listas, tabelas, formulários, semântica, multimídia, atributos globais e acessibilidade.

  • CSS

    As propriedades que dão cor, forma e layout: seletores, cores, texto, caixa, Flexbox, Grid, posição, efeitos e responsividade.

  • JavaScript

    Os comandos que dão vida à página: variáveis, decisões, repetições, funções, eventos e o DOM.

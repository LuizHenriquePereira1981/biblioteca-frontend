Estrutura da página

<!DOCTYPE html>

O que é: a declaração que avisa ao navegador que o documento usa HTML5, a versão atual da linguagem.

Para que serve: garante que o navegador leia a página do jeito moderno, e não em um modo antigo de compatibilidade.

Quando usar: sempre, na primeira linha de todo arquivo HTML.

Exemplo

<!DOCTYPE html>

<html>

O que é: a tag que envolve a página inteira. Todo o resto fica dentro dela.

Para que serve: marcar o início e o fim do documento. O atributo lang informa o idioma, o que ajuda leitores de tela e buscadores.

Quando usar: uma vez por página, logo depois do doctype.

Exemplo

<html lang="pt-BR">
  ...
</html>

<head>

O que é: a parte da página com informações de bastidor, que não aparecem na tela.

Para que serve: guardar o título da aba, o idioma dos caracteres, o link do CSS e outras configurações.

Quando usar: uma vez por página, antes do <body>.

Exemplo

<head>
  <title>Minha página</title>
</head>

<body>

O que é: a parte da página que o visitante vê: textos, imagens, botões e links.

Para que serve: reunir todo o conteúdo visível.

Quando usar: uma vez por página, depois do <head>.

Exemplo

<body>
  <h1>Olá, mundo!</h1>
</body>

<meta>

O que é: uma tag solitária, sem fechamento, que guarda informações sobre a página.

Para que serve: definir a codificação dos caracteres (para os acentos aparecerem certos) e o ajuste da página em telas de celular.

Quando usar: dentro do <head>, uma vez para cada informação.

Exemplo

<meta charset="UTF-8">
<meta name="viewport" content="width=device-width, initial-scale=1.0">

<title>

O que é: o título da página.

Para que serve: aparece na aba do navegador, nos favoritos e nos resultados do Google.

Quando usar: uma vez por página, dentro do <head>.

Exemplo

<title>Biblioteca Front-end</title>

<link>

O que é: uma tag solitária que liga a página a um arquivo externo.

Para que serve: o uso mais comum é ligar o arquivo de estilos CSS. Sem ele, a página aparece sem cores nem layout.

Quando usar: dentro do <head>, uma vez para cada arquivo.

Exemplo

<link rel="stylesheet" href="css/estilo.css">

Textos

<h1> a <h6>

O que é: as tags de título, em seis níveis. O h1 é o mais importante e o h6 o menos importante.

Para que serve: organizar o conteúdo em tópicos e subtópicos. Buscadores e leitores de tela usam os títulos para entender a página.

Quando usar: um h1 por página, para o assunto principal, e os demais níveis em ordem, sem pular. Não use título só para deixar a letra grande, para isso existe o CSS.

Exemplo

<h1>Título principal</h1>
<h2>Subtítulo</h2>
<h3>Tópico</h3>

Resultado

Título principal

Subtítulo

Tópico

<p>

O que é: a tag de parágrafo.

Para que serve: agrupar um bloco de texto. O navegador deixa um espaço antes e depois de cada parágrafo.

Quando usar: para todo texto corrido da página.

Exemplo

<p>Este é um parágrafo.</p>

Resultado

Este é um parágrafo.

<strong>

O que é: a tag que marca um trecho como importante. Por padrão, aparece em negrito.

Para que serve: destacar uma informação que o leitor não pode perder. Leitores de tela dão ênfase a esse trecho.

Quando usar: em avisos e termos-chave. Se for só visual, use o CSS.

Exemplo

<p>Atenção: <strong>salve o arquivo</strong> antes de testar.</p>

Resultado

Atenção: salve o arquivo antes de testar.

<em>

O que é: a tag de ênfase. Por padrão, aparece em itálico.

Para que serve: mudar o tom de uma palavra na frase, como quando você a pronuncia com mais força.

Quando usar: quando a ênfase muda o sentido da frase.

Exemplo

<p>Eu <em>realmente</em> gosto de fotografia.</p>

Resultado

Eu realmente gosto de fotografia.

<span>

O que é: uma tag neutra, que não muda nada por si só, e funciona dentro da linha.

Para que serve: pegar um pedaço do texto para estilizar com CSS ou manipular com JavaScript. Você já usou no contador do portfólio.

Quando usar: quando precisar marcar um trecho dentro de uma frase e não existir uma tag específica.

Exemplo

<p>Contador: <span id="numero">0</span></p>

Resultado

Contador: 0

<hr>

O que é: uma tag solitária que desenha uma linha horizontal.

Para que serve: separar assuntos dentro da página.

Quando usar: quando houver uma mudança de tema dentro de uma mesma seção.

Exemplo

<p>Primeiro assunto</p>
<hr>
<p>Segundo assunto</p>

Resultado

Primeiro assunto

Segundo assunto

<abbr>

O que é: a tag de abreviação ou sigla. O atributo title guarda o significado por extenso.

Para que serve: explicar uma sigla ao visitante, que vê o significado ao passar o mouse.

Quando usar: na primeira vez que uma sigla aparece no texto. Em telas de toque, o title não aparece, então escreva o significado no próprio texto, quando for importante.

Exemplo

<p>O <abbr title="Document Object Model">DOM</abbr> é a árvore da página.</p>

Resultado

O DOM é a árvore da página.

<blockquote>

O que é: a tag de citação em bloco, para um trecho tirado de outra fonte.

Para que serve: destacar uma citação longa, com recuo na margem.

Quando usar: para citações de uma ou mais frases. Para trechos curtos no meio de uma frase, use a tag <q>.

Exemplo

<blockquote>
  <p>Quem não arrisca, não petisca.</p>
</blockquote>

Resultado

Quem não arrisca, não petisca.

<mark>

O que é: a tag que destaca um trecho, como um marca-texto amarelo.

Para que serve: chamar a atenção para uma palavra relevante naquele momento, como o termo buscado.

Quando usar: para realce de relevância. Para importância, o certo é o <strong>.

Exemplo

<p>Aprenda <mark>HTML</mark> passo a passo.</p>

Resultado

Aprenda HTML passo a passo.

<small>

O que é: a tag de letra pequena, para observações laterais.

Para que serve: marcar avisos legais, direitos autorais e notas de rodapé.

Quando usar: para textos secundários. Não use só para diminuir a letra, para isso existe o CSS.

Exemplo

<p><small>Preços sujeitos a alteração.</small></p>

Resultado

Preços sujeitos a alteração.

<sup> e <sub>

O que é: o sup eleva o texto, como um expoente, e o sub o abaixa, como um índice.

Para que serve: escrever potências, notas e fórmulas químicas.

Quando usar: em conteúdo que realmente exige esse formato, como matemática e química.

Exemplo

<p>10<sup>2</sup> e H<sub>2</sub>O</p>

Resultado

102 e H2O

<dl>, <dt> e <dd>

O que é: a lista de descrição. O dl é a lista, o dt é o termo e o dd é a descrição dele.

Para que serve: montar glossários e pares de nome e significado, como esta própria biblioteca.

Quando usar: quando cada item tem um termo e uma explicação. Um termo pode ter várias descrições.

Exemplo

<dl>
  <dt>HTML</dt>
  <dd>Linguagem de marcação</dd>
  <dt>CSS</dt>
  <dd>Linguagem de estilos</dd>
</dl>

Resultado

HTML
Linguagem de marcação
CSS
Linguagem de estilos

Links, imagens e listas

<a>

O que é: a tag de link, também chamada de âncora. O atributo href diz para onde o link leva.

Para que serve: levar o visitante a outra página, a outro site ou a outro ponto da mesma página.

Quando usar: em menus, referências e qualquer texto clicável. Para abrir em outra aba, use target="_blank".

Obs: por segurança, quando o link abre em outra aba, use rel="noopener noreferrer" junto com target="_blank". Isso evita que a página aberta consiga acessar a página original.

Exemplo

<a href="https://www.wikipedia.org" target="_blank" rel="noopener noreferrer">Ir para a Wikipedia</a>

Resultado

Ir para a Wikipedia

<img>

O que é: uma tag solitária que mostra uma imagem. O src é o caminho do arquivo, e o alt é o texto que descreve a imagem.

Para que serve: inserir fotos e ilustrações na página. O alt aparece se a imagem não carregar e é lido por leitores de tela.

Quando usar: sempre que a imagem fizer parte do conteúdo. Escreva um alt que descreva o que a imagem mostra.

Exemplo

<img src="img/luiz.png" alt="Luiz Henrique" width="300">

Resultado

<ul> e <li>

O que é: a lista sem ordem, com marcadores. O li é cada item da lista.

Para que serve: reunir itens que não dependem de sequência, como um menu ou uma lista de compras.

Quando usar: sempre que os itens forem equivalentes entre si. O li só existe dentro de ul ou ol.

Exemplo

<ul>
  <li>Café</li>
  <li>Pão</li>
  <li>Leite</li>
</ul>

Resultado

  • Café
  • Pão
  • Leite

<ol>

O que é: a lista ordenada, numerada automaticamente.

Para que serve: reunir itens em que a ordem importa, como passos de uma receita.

Quando usar: em tutoriais, rankings e qualquer sequência.

Exemplo

<ol>
  <li>Abra o editor</li>
  <li>Escreva o código</li>
  <li>Salve o arquivo</li>
</ol>

Resultado

  1. Abra o editor
  2. Escreva o código
  3. Salve o arquivo

<figure> e <figcaption>

O que é: o figure agrupa um conteúdo ilustrativo, como uma imagem, e o figcaption é a legenda dele.

Para que serve: ligar a legenda à imagem de forma que o navegador e os leitores de tela entendam que as duas andam juntas.

Quando usar: em imagens, gráficos e trechos de código que têm legenda. O figcaption pode ficar antes ou depois do conteúdo.

Exemplo

<figure>
  <img src="img/luiz.png" alt="Luiz Henrique" width="200">
  <figcaption>Luiz Henrique, autor da biblioteca.</figcaption>
</figure>

Resultado

Tabelas e formulários

<table>, <tr>, <th> e <td>

O que é: as tags de tabela. O table é a tabela inteira, o tr é uma linha, o th é uma célula de cabeçalho e o td é uma célula de dados.

Para que serve: organizar informações em linhas e colunas, como preços, horários e comparações.

Quando usar: só para dados de verdade. Para montar o layout da página, use Flexbox ou Grid.

Exemplo

<table>
  <tr>
    <th>Produto</th>
    <th>Preço</th>
  </tr>
  <tr>
    <td>Café</td>
    <td>R$ 12,00</td>
  </tr>
</table>

Resultado

Produto Preço
Café R$ 12,00

<form>

O que é: a tag que envolve um formulário, ou seja, um conjunto de campos que o visitante preenche.

Para que serve: reunir os campos e enviar os dados para um servidor, ou para o JavaScript tratar.

Quando usar: em cadastros, contatos, buscas e logins.

Exemplo

<form>
  <label for="nome">Nome:</label>
  <input type="text" id="nome">
  <button type="submit">Enviar</button>
</form>

Resultado

<input>

O que é: uma tag solitária que cria um campo de entrada. O atributo type define o tipo: texto, e-mail, senha, número, data e outros.

Para que serve: receber o que o visitante digita ou escolhe.

Quando usar: dentro de um formulário. O placeholder mostra uma dica dentro do campo.

Exemplo

<input type="email" placeholder="seu@email.com">

Resultado

<label>

O que é: o rótulo de um campo. O atributo for liga o rótulo ao campo que tem o mesmo id.

Para que serve: dizer ao visitante o que preencher. Ao clicar no rótulo, o cursor vai para o campo, e leitores de tela leem o rótulo junto com ele.

Quando usar: sempre que houver um campo.

Exemplo

<label for="cidade">Cidade:</label>
<input type="text" id="cidade">

Resultado

<button>

O que é: a tag de botão.

Para que serve: receber o clique do visitante. Dentro de um formulário, com type="submit", ele envia os dados. Fora dele, o JavaScript pode reagir ao clique.

Quando usar: para ações, como enviar, somar ou zerar. Para ir a outra página, use o link <a>.

Exemplo

<button>Clique aqui</button>

Resultado

<textarea>

O que é: um campo de texto de várias linhas.

Para que serve: receber textos longos, como mensagens e comentários.

Quando usar: quando o input de uma linha só não basta. Os atributos rows e cols definem a altura e a largura iniciais.

Exemplo

<textarea rows="3" cols="30" placeholder="Escreva sua mensagem"></textarea>

Resultado

<select> e <option>

O que é: a lista suspensa. O select é a caixa, e cada option é uma escolha.

Para que serve: deixar o visitante escolher uma opção de uma lista pronta, como o estado ou a cidade.

Quando usar: quando há muitas opções fixas. O atributo value de cada option é o que o formulário envia.

Exemplo

<select>
  <option value="sp">São Paulo</option>
  <option value="rj">Rio de Janeiro</option>
</select>

Resultado

type="checkbox"

O que é: uma caixinha de marcar, que pode ficar ligada ou desligada.

Para que serve: permitir que o visitante marque várias opções, ou aceite algo, como os termos de uso.

Quando usar: quando cada opção é independente das outras. O atributo checked deixa a caixinha marcada desde o começo.

Exemplo

<input type="checkbox" id="html">
<label for="html">Gosto de HTML</label>

Resultado

type="radio"

O que é: uma bolinha de escolha. Só uma do grupo pode ficar marcada.

Para que serve: obrigar o visitante a escolher uma única opção entre algumas.

Quando usar: para escolhas exclusivas, como sim ou não. O que une as bolinhas num grupo é o mesmo atributo name.

Exemplo

<input type="radio" name="nivel" id="iniciante">
<label for="iniciante">Iniciante</label>
<input type="radio" name="nivel" id="intermediario">
<label for="intermediario">Intermediário</label>
<input type="radio" name="nivel" id="avancado">
<label for="avancado">Avançado</label>

Resultado

required

O que é: um atributo que torna o campo obrigatório.

Para que serve: impedir o envio do formulário com o campo vazio. O próprio navegador mostra o aviso.

Quando usar: nos campos sem os quais o formulário não faz sentido, como o e-mail de um cadastro.

Exemplo

<input type="text" required>

Resultado

<thead>, <tbody>, <tfoot> e <caption>

O que é: as tags que organizam uma tabela em partes. O thead é o cabeçalho, o tbody é o corpo, o tfoot é o rodapé e o caption é a legenda.

Para que serve: deixar a estrutura da tabela clara para leitores de tela e permitir estilizar cada parte separadamente.

Quando usar: em tabelas de dados. O caption deve ser o primeiro filho do table.

Exemplo

<table>
  <caption>Preços</caption>
  <thead>
    <tr><th>Produto</th><th>Preço</th></tr>
  </thead>
  <tbody>
    <tr><td>Café</td><td>R$ 12,00</td></tr>
    <tr><td>Pão</td><td>R$ 8,00</td></tr>
  </tbody>
  <tfoot>
    <tr><td>Total</td><td>R$ 20,00</td></tr>
  </tfoot>
</table>

Resultado

Preços
Produto Preço
Café R$ 12,00
Pão R$ 8,00
Total R$ 20,00

colspan e rowspan

O que é: atributos de célula que fazem uma célula ocupar mais de uma coluna (colspan) ou mais de uma linha (rowspan).

Para que serve: montar tabelas com títulos que abrangem várias colunas, como um cabeçalho de grupo.

Quando usar: quando o dado se aplica a várias células. O número é a quantidade de colunas ou linhas ocupadas, e as células que sobrarem na linha devem ser removidas.

Exemplo

<table>
  <tr>
    <th colspan="2">Cardápio</th>
  </tr>
  <tr>
    <td>Café</td>
    <td>R$ 12,00</td>
  </tr>
</table>

Resultado

Cardápio
Café R$ 12,00

Estrutura semântica

<header>

O que é: o cabeçalho de uma página ou de uma seção.

Para que serve: reunir o título, o logotipo e o menu de navegação.

Quando usar: geralmente um no topo da página. Também pode aparecer dentro de um <article>, com o título daquele conteúdo.

Exemplo

<header>
  <h1>Meu site</h1>
</header>

<nav>

O que é: o bloco de navegação, com os links principais.

Para que serve: mostrar ao visitante para onde ele pode ir. Leitores de tela reconhecem a nav como o menu.

Quando usar: em menus principais e sumários. Não é para qualquer grupo de links, só para os de navegação importante.

Exemplo

<nav>
  <a href="index.html">Início</a>
  <a href="html.html">HTML</a>
</nav>

<main>

O que é: o conteúdo principal da página.

Para que serve: marcar a parte que é única daquela página, sem o cabeçalho e o rodapé que se repetem em todas.

Quando usar: uma vez por página, e nunca dentro de header, nav ou footer.

Exemplo

<main>
  <h2>Bem-vindo</h2>
</main>

<section>

O que é: uma seção temática da página.

Para que serve: agrupar conteúdos que tratam do mesmo assunto, geralmente com um título.

Quando usar: quando o bloco tem um tema e um título próprio. Se for só para estilizar, use a <div>.

Exemplo

<section id="sobre">
  <h2>Sobre</h2>
  <p>Texto da seção.</p>
</section>

<article>

O que é: um conteúdo completo, que faz sentido sozinho, mesmo fora da página.

Para que serve: marcar itens independentes, como uma notícia, um post de blog ou um verbete desta biblioteca.

Quando usar: quando o bloco poderia ser publicado separadamente em outro lugar.

Exemplo

<article>
  <h3>Título do post</h3>
  <p>Conteúdo do post.</p>
</article>

<aside>

O que é: um conteúdo complementar, relacionado ao principal.

Para que serve: reunir dicas, barras laterais, anúncios e links relacionados.

Quando usar: para o que dá para tirar sem prejudicar o entendimento do conteúdo principal.

Exemplo

<aside>
  <h3>Dica</h3>
  <p>Salve o arquivo antes de testar.</p>
</aside>

<footer>

O que é: o rodapé de uma página ou de uma seção.

Para que serve: reunir autoria, direitos autorais, contatos e links secundários.

Quando usar: geralmente um no fim da página. Também pode aparecer dentro de um <article>.

Exemplo

<footer>
  <p>&copy; 2026 Luiz Henrique</p>
</footer>

<div>

O que é: uma caixa neutra, sem significado próprio, que funciona como bloco.

Para que serve: agrupar elementos para estilizar com CSS ou manipular com JavaScript, como os cartões do seu portfólio.

Quando usar: quando nenhuma tag semântica serve. É o equivalente em bloco do <span>, que é em linha.

Exemplo

<div class="cartao">
  <h3>Fotografia</h3>
</div>

Texto e código

<br>

O que é: uma tag que quebra a linha, ou seja, faz o texto continuar na linha de baixo.

Para que serve: separar linhas dentro de um mesmo parágrafo, como em endereços, poemas ou versos de música.

Quando usar: só quando a quebra faz parte do conteúdo. Para criar espaço entre blocos de texto, use parágrafos separados ou o CSS.

Exemplo

<p>Rua das Flores, 100<br>São Paulo - SP</p>

Resultado

Rua das Flores, 100
São Paulo - SP

&lt; e &gt;

O que é: entidades HTML, que são códigos que mostram os símbolos de menor (<) e de maior (>) como texto na tela.

Para que serve: exibir uma tag na página sem o navegador executá-la. Sem isso, o navegador acharia que o símbolo abre uma tag.

Quando usar: sempre que precisar mostrar código HTML escrito na tela, como nesta biblioteca. Toda entidade começa com & e termina com ponto e vírgula.

Exemplo

&lt;p&gt;Olá&lt;/p&gt;

Resultado

<p>Olá</p>

<pre>

O que é: uma tag de texto pré-formatado. Ela mostra o texto exatamente como foi escrito, com os espaços e as quebras de linha.

Para que serve: exibir trechos em que a formatação importa, como código, poemas e tabelas feitas com texto.

Quando usar: junto com a tag <code>, para mostrar blocos de código de várias linhas.

Exemplo

<pre>
Linha 1
    Linha 2 com recuo
</pre>

Resultado

Linha 1
    Linha 2 com recuo

<code>

O que é: uma tag que marca um trecho como código de programação.

Para que serve: indicar ao navegador, e a quem lê, que aquele texto é código. Por padrão, ele aparece em fonte de largura fixa.

Quando usar: em trechos curtos, no meio de uma frase, ou dentro do <pre> para blocos maiores.

Exemplo

<p>Use a tag <code>&lt;br&gt;</code> para quebrar a linha.</p>

Resultado

Use a tag <br> para quebrar a linha.

Multimídia

<audio>

O que é: a tag que coloca um player de áudio na página.

Para que serve: tocar músicas, podcasts e gravações sem precisar de programas externos.

Quando usar: sempre com o atributo controls, que mostra os botões de tocar e pausar. Evite o autoplay, porque o som que começa sozinho incomoda e os navegadores costumam bloquear.

Exemplo

<audio controls src="audio/musica.mp3">
  Seu navegador não suporta áudio.
</audio>

Resultado

Para ver o player, coloque um arquivo em uma pasta audio e ajuste o nome no src.

<video>

O que é: a tag que coloca um player de vídeo na página.

Para que serve: exibir vídeos hospedados no próprio site, com controles de tocar, pausar e tela cheia.

Quando usar: para vídeos curtos e leves. Os atributos controls e width são os mais usados, e o poster define a imagem de capa antes de tocar.

Exemplo

<video controls width="400" poster="img/capa.jpg">
  <source src="video/aula.mp4" type="video/mp4">
  Seu navegador não suporta vídeo.
</video>

Resultado

Para ver o player, coloque um arquivo em uma pasta video e ajuste os nomes no exemplo.

<iframe>

O que é: uma janela que mostra outra página dentro da sua.

Para que serve: incorporar vídeos do YouTube, mapas do Google e outros conteúdos de fora.

Quando usar: quando o conteúdo está hospedado em outro serviço. Use sempre o atributo title, que descreve o conteúdo para leitores de tela.

Exemplo

<iframe src="https://www.wikipedia.org" width="400" height="250" title="Wikipedia"></iframe>

Resultado

Alguns sites bloqueiam a incorporação, e a janela fica em branco. Para um teste seguro, use o endereço de incorporação que o próprio YouTube oferece em Compartilhar e depois Incorporar.

Atributos globais

class

O que é: um nome de grupo que você dá a um ou mais elementos.

Para que serve: aplicar o mesmo estilo CSS, ou o mesmo comportamento do JavaScript, a vários elementos de uma vez.

Quando usar: sempre que o estilo se repetir. Diferente do id, a mesma classe pode aparecer quantas vezes você quiser, e um elemento pode ter várias classes separadas por espaço.

Exemplo

<p class="destaque">Texto em destaque</p>

Resultado

Texto em destaque

id

O que é: um identificador único para um elemento.

Para que serve: criar links internos, como os do índice desta página, e permitir que o JavaScript encontre o elemento com getElementById.

Quando usar: para elementos que precisam ser localizados individualmente. O valor não pode se repetir na página.

Exemplo

<section id="sobre">...</section>
<a href="#sobre">Ir para Sobre</a>

style

O que é: um atributo que recebe regras de CSS escritas direto na tag.

Para que serve: aplicar um estilo rápido a um único elemento, sem criar regra no arquivo CSS.

Quando usar: só em testes rápidos ou em valores que o JavaScript muda. Para o resto, prefira class e o arquivo CSS, que fica mais organizado e fácil de manter.

Exemplo

<p style="color: green; font-weight: bold;">Texto verde</p>

Resultado

Texto verde

title

O que é: um texto de ajuda que aparece quando o mouse fica parado sobre o elemento.

Para que serve: dar uma explicação extra, como o significado de uma sigla.

Quando usar: em informações complementares. Não conte com ele para o essencial, porque não aparece no celular, que não tem mouse.

Exemplo

<p>Usamos <abbr title="HyperText Markup Language">HTML</abbr>.</p>

Resultado

Usamos HTML.

hidden

O que é: um atributo que esconde o elemento da página.

Para que serve: manter um conteúdo no HTML sem mostrá-lo, para o JavaScript revelar depois, como uma mensagem de erro ou um menu.

Quando usar: para conteúdo que só aparece em certas situações. O elemento continua no código, mas não aparece na tela.

Exemplo

<p hidden>Você não me vê.</p>

Resultado

O parágrafo escondido está logo aqui, e você não o vê: (nada aparece de propósito)

Você não me vê.

Acessibilidade

alt

O que é: o texto alternativo de uma imagem, escrito no atributo alt da tag <img>.

Para que serve: descrever a imagem para quem não pode vê-la, como pessoas que usam leitor de tela. Também aparece se a imagem não carregar.

Quando usar: em toda imagem que tem significado, descrevendo o que ela mostra. Se a imagem for só decoração, deixe o alt vazio, assim: alt="".

Exemplo

<img src="img/luiz.png" alt="Luiz Henrique sorrindo" width="150">

lang

O que é: o atributo que informa o idioma do conteúdo.

Para que serve: ajuda o leitor de tela a escolher a pronúncia certa e os navegadores a oferecerem tradução.

Quando usar: na tag <html>, para a página inteira. Também pode ir em um trecho em outro idioma.

Exemplo

<html lang="pt-BR">
<p>Ele disse <span lang="en">hello</span>.</p>

aria-label

O que é: um atributo que dá um nome a um elemento para os leitores de tela, sem aparecer na tela.

Para que serve: descrever elementos que não têm texto, como um botão que só tem um ícone ou uma seta.

Quando usar: quando o elemento não tem texto visível que explique o que ele faz. Se já existe texto, não precisa.

Exemplo

<a href="#" aria-label="Voltar ao topo">↑</a>

Resultado

É o mesmo que o botão de voltar ao topo no canto desta página.

Títulos em ordem

O que é: o uso das tags de título, h1 a h6, na sequência certa, sem pular níveis.

Para que serve: quem usa leitor de tela navega pela página saltando de título em título, como se fosse um índice.

Quando usar: sempre. Um h1 por página, depois h2 para as seções e h3 para as partes. Não escolha o título pelo tamanho da letra, para isso existe o CSS.

Exemplo

<h1>Meu site</h1>
<h2>Sobre</h2>
<h3>Minha história</h3>

<label> ligado ao campo

O que é: o rótulo de um campo de formulário, ligado a ele pelo for e pelo id.

Para que serve: o leitor de tela lê o rótulo junto com o campo, e o clique no rótulo leva o cursor ao campo, o que ajuda quem tem dificuldade de acertar áreas pequenas.

Quando usar: em todo campo de formulário. O placeholder sozinho não substitui o rótulo.

Exemplo

<label for="email">E-mail:</label>
<input type="email" id="email">

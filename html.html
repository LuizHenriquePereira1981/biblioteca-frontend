Comandos de HTML

Estrutura da página

<!DOCTYPE html>

O que é: a declaração que avisa ao navegador que o documento usa HTML5, a versão atual da linguagem.

Para que serve: garante que o navegador leia a página do jeito moderno, e não em um modo antigo de compatibilidade.

Quando usar: sempre, na primeira linha de todo arquivo HTML.

Exemplo

<!DOCTYPE html>

<html>

O que é: a tag que envolve a página inteira. Todo o resto fica dentro dela.

Para que serve: marcar o início e o fim do documento. O atributo lang informa o idioma, o que ajuda leitores de tela e buscadores.

Quando usar: uma vez por página, logo depois do doctype.

Exemplo

<html lang="pt-BR">
  ...
</html>

<head>

O que é: a parte da página com informações de bastidor, que não aparecem na tela.

Para que serve: guardar o título da aba, o idioma dos caracteres, o link do CSS e outras configurações.

Quando usar: uma vez por página, antes do <body>.

Exemplo

<head>
  <title>Minha página</title>
</head>

<body>

O que é: a parte da página que o visitante vê: textos, imagens, botões e links.

Para que serve: reunir todo o conteúdo visível.

Quando usar: uma vez por página, depois do <head>.

Exemplo

<body>
  <h1>Olá, mundo!</h1>
</body>

<meta>

O que é: uma tag solitária, sem fechamento, que guarda informações sobre a página.

Para que serve: definir a codificação dos caracteres (para os acentos aparecerem certos) e o ajuste da página em telas de celular.

Quando usar: dentro do <head>, uma vez para cada informação.

Exemplo

<meta charset="UTF-8">
<meta name="viewport" content="width=device-width, initial-scale=1.0">

<title>

O que é: o título da página.

Para que serve: aparece na aba do navegador, nos favoritos e nos resultados do Google.

Quando usar: uma vez por página, dentro do <head>.

Exemplo

<title>Biblioteca Front-end</title>

<link>

O que é: uma tag solitária que liga a página a um arquivo externo.

Para que serve: o uso mais comum é ligar o arquivo de estilos CSS. Sem ele, a página aparece sem cores nem layout.

Quando usar: dentro do <head>, uma vez para cada arquivo.

Exemplo

<link rel="stylesheet" href="css/estilo.css">

Textos

<h1> a <h6>

O que é: as tags de título, em seis níveis. O h1 é o mais importante e o h6 o menos importante.

Para que serve: organizar o conteúdo em tópicos e subtópicos. Buscadores e leitores de tela usam os títulos para entender a página.

Quando usar: um h1 por página, para o assunto principal, e os demais níveis em ordem, sem pular. Não use título só para deixar a letra grande, para isso existe o CSS.

Exemplo

<h1>Título principal</h1>
<h2>Subtítulo</h2>
<h3>Tópico</h3>

Resultado

Título principal

Subtítulo

Tópico

<p>

O que é: a tag de parágrafo.

Para que serve: agrupar um bloco de texto. O navegador deixa um espaço antes e depois de cada parágrafo.

Quando usar: para todo texto corrido da página.

Exemplo

<p>Este é um parágrafo.</p>

Resultado

Este é um parágrafo.

<strong>

O que é: a tag que marca um trecho como importante. Por padrão, aparece em negrito.

Para que serve: destacar uma informação que o leitor não pode perder. Leitores de tela dão ênfase a esse trecho.

Quando usar: em avisos e termos-chave. Se for só visual, use o CSS.

Exemplo

<p>Atenção: <strong>salve o arquivo</strong> antes de testar.</p>

Resultado

Atenção: salve o arquivo antes de testar.

<em>

O que é: a tag de ênfase. Por padrão, aparece em itálico.

Para que serve: mudar o tom de uma palavra na frase, como quando você a pronuncia com mais força.

Quando usar: quando a ênfase muda o sentido da frase.

Exemplo

<p>Eu <em>realmente</em> gosto de fotografia.</p>

Resultado

Eu realmente gosto de fotografia.

<span>

O que é: uma tag neutra, que não muda nada por si só, e funciona dentro da linha.

Para que serve: pegar um pedaço do texto para estilizar com CSS ou manipular com JavaScript. Você já usou no contador do portfólio.

Quando usar: quando precisar marcar um trecho dentro de uma frase e não existir uma tag específica.

Exemplo

<p>Contador: <span id="numero">0</span></p>

Resultado

Contador: 0

<hr>

O que é: uma tag solitária que desenha uma linha horizontal.

Para que serve: separar assuntos dentro da página.

Quando usar: quando houver uma mudança de tema dentro de uma mesma seção.

Exemplo

<p>Primeiro assunto</p>
<hr>
<p>Segundo assunto</p>

Resultado

Primeiro assunto

Segundo assunto

Links, imagens e listas

<a>

O que é: a tag de link, também chamada de âncora. O atributo href diz para onde o link leva.

Para que serve: levar o visitante a outra página, a outro site ou a outro ponto da mesma página.

Quando usar: em menus, referências e qualquer texto clicável. Para abrir em outra aba, use target="_blank".

Exemplo

<a href="https://www.wikipedia.org">Ir para a Wikipedia</a>

Resultado

Ir para a Wikipedia

<img>

O que é: uma tag solitária que mostra uma imagem. O src é o caminho do arquivo, e o alt é o texto que descreve a imagem.

Para que serve: inserir fotos e ilustrações na página. O alt aparece se a imagem não carregar e é lido por leitores de tela.

Quando usar: sempre que a imagem fizer parte do conteúdo. Escreva um alt que descreva o que a imagem mostra.

Exemplo

<img src="img/luiz.png" alt="Luiz Henrique" width="300">

Resultado

<ul> e <li>

O que é: a lista sem ordem, com marcadores. O li é cada item da lista.

Para que serve: reunir itens que não dependem de sequência, como um menu ou uma lista de compras.

Quando usar: sempre que os itens forem equivalentes entre si. O li só existe dentro de ul ou ol.

Exemplo

<ul>
  <li>Café</li>
  <li>Pão</li>
  <li>Leite</li>
</ul>

Resultado

  • Café
  • Pão
  • Leite

<ol>

O que é: a lista ordenada, numerada automaticamente.

Para que serve: reunir itens em que a ordem importa, como passos de uma receita.

Quando usar: em tutoriais, rankings e qualquer sequência.

Exemplo

<ol>
  <li>Abra o editor</li>
  <li>Escreva o código</li>
  <li>Salve o arquivo</li>
</ol>

Resultado

  1. Abra o editor
  2. Escreva o código
  3. Salve o arquivo

<br>

O que é: uma tag que quebra a linha, ou seja, faz o texto continuar na linha de baixo.

Para que serve: separar linhas dentro de um mesmo parágrafo, como em endereços, poemas ou versos de música.

Quando usar: só quando a quebra faz parte do conteúdo. Para criar espaço entre blocos de texto, use parágrafos separados ou o CSS.

Exemplo

<p>Rua das Flores, 100<br>São Paulo - SP</p>

Resultado

Rua das Flores, 100
São Paulo - SP

&lt; e &gt;

O que é: entidades HTML, que são códigos que mostram os símbolos de menor (<) e de maior (>) como texto na tela.

Para que serve: exibir uma tag na página sem o navegador executá-la. Sem isso, o navegador acharia que o símbolo abre uma tag.

Quando usar: sempre que precisar mostrar código HTML escrito na tela, como nesta biblioteca. Toda entidade começa com & e termina com ponto e vírgula.

Exemplo

&lt;p&gt;Olá&lt;/p&gt;

Resultado

<p>Olá</p>

<pre>

O que é: uma tag de texto pré-formatado. Ela mostra o texto exatamente como foi escrito, com os espaços e as quebras de linha.

Para que serve: exibir trechos em que a formatação importa, como código, poemas e tabelas feitas com texto.

Quando usar: junto com a tag <code>, para mostrar blocos de código de várias linhas.

Exemplo

<pre>
Linha 1
    Linha 2 com recuo
</pre>

Resultado

Linha 1
    Linha 2 com recuo

<code>

O que é: uma tag que marca um trecho como código de programação.

Para que serve: indicar ao navegador, e a quem lê, que aquele texto é código. Por padrão, ele aparece em fonte de largura fixa.

Quando usar: em trechos curtos, no meio de uma frase, ou dentro do <pre> para blocos maiores.

Exemplo

<p>Use a tag <code>&lt;br&gt;</code> para quebrar a linha.</p>

Resultado

Use a tag <br> para quebrar a linha.

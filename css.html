Seletores

seletor de tag

O que é: o seletor que escolhe todos os elementos de um tipo, escrevendo só o nome da tag.

Para que serve: aplicar o mesmo estilo a todos os parágrafos, títulos ou links de uma vez.

Quando usar: para estilos gerais da página. Para casos específicos, use classe ou id.

Exemplo

p {
  color: darkblue;
}

.classe

O que é: o seletor que escolhe os elementos que têm uma classe, escrito com um ponto antes do nome.

Para que serve: estilizar um grupo de elementos, de tags diferentes, de uma vez.

Quando usar: é o seletor mais usado no dia a dia, porque é flexível e pode se repetir.

Exemplo

.destaque {
  background-color: yellow;
}

#id

O que é: o seletor que escolhe um único elemento pelo seu id, escrito com uma cerquilha antes do nome.

Para que serve: estilizar um elemento específico, que aparece uma vez na página.

Quando usar: com moderação. Como o id é único, o seletor serve só para um elemento, e a classe costuma ser mais flexível.

Exemplo

#topo {
  background-color: black;
}

Cores e fundos

color

O que é: a propriedade que define a cor do texto.

Para que serve: mudar a cor das letras de um elemento.

Quando usar: sempre cuidando do contraste com o fundo, para o texto continuar legível.

Exemplo

p {
  color: #1a1a1a;
}

Resultado

Este texto está em vermelho escuro.

background-color

O que é: a propriedade que define a cor de fundo.

Para que serve: pintar o fundo de um elemento ou da página.

Quando usar: em caixas, cabeçalhos, botões e destaques. Combine com uma color que contraste.

Exemplo

.aviso {
  background-color: #fff3b0;
}

Resultado

Este parágrafo tem fundo amarelo claro.

Texto e fontes

font-family

O que é: a propriedade que define a fonte do texto.

Para que serve: escolher o tipo de letra. Você escreve uma lista, e o navegador usa a primeira que existir no computador de quem visita.

Quando usar: sempre termine a lista com uma família genérica, como serif (com serifa), sans-serif (sem serifa) ou monospace (largura fixa), que serve de reserva.

Exemplo

p {
  font-family: Georgia, "Times New Roman", serif;
}

Resultado

Texto em fonte com serifa.

Texto em fonte sem serifa.

font-size

O que é: a propriedade que define o tamanho da letra.

Para que serve: aumentar ou diminuir o texto.

Quando usar: prefira rem ou em a px, porque acompanham a configuração de tamanho do navegador de quem lê. O 1rem equivale ao tamanho padrão da página, em geral 16px.

Exemplo

h2 {
  font-size: 1.5rem;
}

Resultado

Texto pequeno, 0.9rem.

Texto grande, 1.5rem.

font-weight

O que é: a propriedade que define a espessura da letra.

Para que serve: deixar o texto em negrito ou mais fino.

Quando usar: use bold ou números de 100 a 900. O valor normal equivale a 400, e o bold a 700.

Exemplo

.forte {
  font-weight: bold;
}

Resultado

Texto normal.

Texto em negrito.

text-align

O que é: a propriedade que alinha o texto na horizontal.

Para que serve: posicionar o texto à esquerda, ao centro, à direita ou justificado.

Quando usar: o center funciona bem em títulos e botões. Em textos longos, prefira o left, que é mais fácil de ler.

Exemplo

h1 {
  text-align: center;
}

Resultado

Alinhado à esquerda.

Alinhado ao centro.

Alinhado à direita.

line-height

O que é: a propriedade que define a altura da linha, ou seja, o espaço entre uma linha de texto e a outra.

Para que serve: deixar o texto mais arejado e confortável de ler.

Quando usar: em textos longos, com um número sem unidade, como 1.6. Esse número multiplica o tamanho da letra.

Exemplo

p {
  line-height: 1.7;
}

text-decoration

O que é: a propriedade que adiciona ou remove linhas no texto, como o sublinhado.

Para que serve: tirar o sublinhado padrão dos links, ou riscar um texto.

Quando usar: em links de menu, com none. Em links dentro de texto, mantenha o sublinhado, porque ele ajuda a identificar o que é clicável.

Exemplo

a {
  text-decoration: none;
}

Resultado

Sublinhado.

Riscado.

Caixa e espaçamento

O modelo de caixa

O que é: a ideia de que todo elemento da página é uma caixa, formada por quatro camadas, de dentro para fora: o conteúdo, o padding, a border e o margin.

Para que serve: entender o tamanho e o espaço de cada elemento, que é a base de qualquer layout.

Quando usar: sempre que algo na página estiver maior, menor ou mais colado do que o esperado, a causa quase sempre está nessas camadas.

Exemplo

.caixa {
  padding: 20px;
  border: 3px solid black;
  margin: 30px;
}

Resultado

Caixa com padding de 20px e borda de 3px.

padding

O que é: o espaço interno, entre o conteúdo e a borda.

Para que serve: afastar o texto das bordas da caixa, para ele não ficar colado.

Quando usar: em botões, cartões, cabeçalhos e qualquer caixa com fundo ou borda. Dá para escrever um valor para os quatro lados, ou dois valores: o primeiro para cima e baixo, o segundo para esquerda e direita.

Exemplo

.botao {
  padding: 8px 16px;
}

Resultado

Padding de 8px por 16px.

margin

O que é: o espaço externo, entre a caixa e os elementos vizinhos.

Para que serve: separar uma caixa da outra.

Quando usar: para dar distância entre blocos. O truque margin: 0 auto centraliza uma caixa que tem largura definida, e você já o usou no main desta biblioteca.

Exemplo

.cartao {
  margin: 0 auto;
  width: 300px;
}

border

O que é: a propriedade que desenha uma borda em volta da caixa.

Para que serve: destacar e delimitar um elemento. Ela junta três valores: a espessura, o estilo e a cor.

Quando usar: em cartões, campos de formulário e destaques. Para cantos arredondados, combine com o border-radius.

Exemplo

.cartao {
  border: 2px solid #3b2a1a;
  border-radius: 8px;
}

Resultado

Borda de 2px, sólida, com cantos arredondados.

box-sizing

O que é: a propriedade que define como o tamanho da caixa é calculado.

Para que serve: por padrão, o width mede só o conteúdo, e o padding e a borda são somados por fora. Com border-box, o width já inclui o padding e a borda, e a conta fica mais previsível.

Quando usar: quase sempre, aplicado a todos os elementos com o seletor universal, no começo do arquivo CSS.

Exemplo

* {
  box-sizing: border-box;
}

width e height

O que é: as propriedades que definem a largura e a altura de um elemento.

Para que serve: controlar o tamanho de caixas, imagens e botões.

Quando usar: a largura costuma ser definida, e a altura é melhor deixar que o conteúdo decida. O max-width limita a largura máxima, e funciona muito bem para páginas responsivas.

Exemplo

main {
  max-width: 900px;
  margin: 0 auto;
}

Layout: Flexbox e Grid

display: flex

O que é: o modo de layout que organiza os filhos de um elemento em uma linha ou em uma coluna.

Para que serve: alinhar e distribuir itens, como os cartões do portfólio e o cabeçalho desta biblioteca.

Quando usar: para layouts em uma direção, como menus, cartões lado a lado e centralização. A regra vai no elemento pai, e quem muda de posição são os filhos.

Exemplo

.cartoes {
display: flex;
gap: 20px;
}

Resultado

Um
Dois
Três

justify-content e align-items

O que é: as propriedades do Flexbox que posicionam os itens: o justify-content no sentido da linha (horizontal), e o align-items no sentido contrário (vertical).

Para que serve: centralizar, afastar ou distribuir os itens dentro do pai.

Quando usar: o center centraliza, o space-between joga o primeiro item para um canto e o último para o outro, e o space-around distribui espaços iguais em volta.

Exemplo

.barra {
display: flex;
justify-content: space-between;
align-items: center;
}

Resultado

Esquerda Direita

flex-wrap e flex-direction

O que é: o flex-wrap permite que os itens quebrem de linha quando não cabem, e o flex-direction troca a direção, de linha para coluna.

Para que serve: adaptar o layout ao tamanho da tela. É o que empilha os cartões no celular.

Quando usar: o wrap em grupos de cartões, e o column em telas pequenas, dentro de uma media query.

Exemplo

.cartoes {
display: flex;
flex-wrap: wrap;
}

display: grid

O que é: o modo de layout que organiza os filhos em linhas e colunas ao mesmo tempo, como uma tabela de verdade.

Para que serve: montar galerias, painéis e o layout da página inteira.

Quando usar: quando o desenho precisa de duas direções. O grid-template-columns define as colunas, e o 1fr significa uma fração do espaço disponível.

Exemplo

.galeria {
display: grid;
grid-template-columns: 1fr 1fr 1fr;
gap: 10px;
}

gap

O que é: a propriedade que define o espaço entre os itens de um Flexbox ou de um Grid.

Para que serve: afastar os itens uns dos outros sem precisar de margin em cada um.

Quando usar: sempre que usar Flexbox ou Grid. Aceita um valor para os dois sentidos, ou dois valores: primeiro as linhas, depois as colunas.

Exemplo

.grade {
display: grid;
gap: 20px 10px;
}

Posição e efeitos

position

O que é: a propriedade que define como um elemento é posicionado na página.

Para que serve: tirar um elemento do fluxo normal, para colocá-lo num lugar exato ou fazê-lo acompanhar a rolagem.

Quando usar: o fixed gruda na tela, como o botão de voltar ao topo desta página. O sticky gruda depois de chegar a certo ponto, como o cabeçalho. O absolute posiciona em relação ao pai mais próximo que tenha position: relative.

Exemplo

header {
position: sticky;
top: 0;
}

Resultado

Canto inferior direito

z-index

O que é: a propriedade que define quem fica na frente quando dois elementos se sobrepõem.

Para que serve: garantir que o cabeçalho fixo fique por cima do conteúdo que rola.

Quando usar: só funciona em elementos com position diferente do padrão. Quanto maior o número, mais perto de quem olha.

Exemplo

header {
position: sticky;
z-index: 100;
}

box-shadow

O que é: a propriedade que desenha uma sombra em volta da caixa.

Para que serve: dar profundidade a cartões e botões.

Quando usar: com os valores de deslocamento horizontal, deslocamento vertical, desfoque e cor. Uma sombra suave e transparente costuma ficar mais elegante que uma forte.

Exemplo

.cartao {
box-shadow: 0 4px 8px rgba(0, 0, 0, 0.2);
}

Resultado

Cartão com sombra suave.

transition

O que é: a propriedade que faz uma mudança de estilo acontecer de forma suave, em vez de instantânea.

Para que serve: animar o efeito de passar o mouse, como nos cartões do seu portfólio.

Quando usar: no elemento que vai mudar, indicando qual propriedade e quanto tempo dura. Sem ela, a mudança do :hover é brusca.

Exemplo

.cartao {
transition: transform 0.3s ease;
}
.cartao:hover {
transform: translateY(-4px);
}

transform

O que é: a propriedade que move, gira, aumenta ou inclina um elemento sem mexer no resto do layout.

Para que serve: efeitos visuais, como subir um cartão ao passar o mouse.

Quando usar: com funções como translateY (move na vertical), rotate (gira) e scale (muda o tamanho). Funciona muito bem junto com a transition.

Exemplo

.icone {
transform: rotate(10deg) scale(1.1);
}

Resultado

Texto girado em 5 graus.

:hover

O que é: uma pseudo-classe, ou seja, um estado do elemento. Vale quando o mouse está em cima dele.

Para que serve: mudar o estilo ao passar o mouse, como a cor de um link.

Quando usar: em links, botões e cartões, para avisar que são clicáveis. No celular, que não tem mouse, o efeito não aparece, então não esconda informação essencial nele.

Exemplo

a:hover {
color: darkred;
}

Responsividade

@media

O que é: a media query, uma regra que só vale quando a tela atende a uma condição, como ter uma largura máxima.

Para que serve: adaptar o layout ao tamanho da tela, por exemplo empilhando cartões no celular.

Quando usar: para ajustar o que não cabe em telas pequenas. O max-width vale até aquela largura, e o min-width vale a partir dela. Uma largura comum para separar o celular é 768px.

Exemplo

@media (max-width: 768px) {
.cartao {
width: 100%;
}
}

A tag viewport

O que é: a tag <meta> do <head> que diz ao celular para usar a largura real da tela.

Para que serve: sem ela, o celular finge ter uma tela larga e encolhe tudo, e as media queries não funcionam direito.

Quando usar: em todas as páginas, sempre no <head>.

Exemplo

<meta name="viewport" content="width=device-width, initial-scale=1.0">

Unidades relativas

O que é: medidas que se ajustam ao contexto, em vez de valer um número fixo de pixels. As principais são %, rem, vw e vh.

Para que serve: o % é uma fração do elemento pai, o rem acompanha o tamanho padrão da letra da página, e o vw e o vh são 1% da largura e da altura da tela.

Quando usar: o rem para fontes e espaços, o % para larguras flexíveis, e o vh para seções que devem ocupar parte da tela, como o min-height: 70vh do parallax do guia.

Exemplo

.caixa {
width: 50%;
padding: 1rem;
min-height: 30vh;
}

max-width com imagens

O que é: o truque de limitar a largura das imagens ao tamanho do espaço onde estão.

Para que serve: impedir que uma imagem grande estoure a tela do celular.

Quando usar: em todas as imagens do site. Com height: auto, a altura acompanha, e a imagem não fica distorcida.

Exemplo

img {
max-width: 100%;
height: auto;
}

Mobile first

O que é: a prática de escrever o CSS pensando primeiro no celular, e depois acrescentar regras para telas maiores.

Para que serve: a maior parte dos visitantes usa o celular, e é mais simples ampliar um layout simples do que encolher um complicado.

Quando usar: em projetos novos, escrevendo o estilo base para a tela pequena, e usando @media (min-width: ...) para as maiores.

Exemplo

.cartoes {
display: flex;
flex-direction: column;
}

@media (min-width: 768px) {
.cartoes {
flex-direction: row;
}
}

Variáveis e recursos avançados

Variáveis CSS (--nome e var())

O que é: um jeito de guardar um valor, como uma cor, com um nome, para usar em vários lugares. O nome começa com dois hífens, e o var() usa o valor guardado.

Para que serve: mudar a cor do site inteiro mexendo em um lugar só, em vez de trocar o código em cada regra.

Quando usar: para cores, fontes e espaços que se repetem. As variáveis ficam dentro de :root, que representa a página inteira.

Exemplo

:root {
  --marrom: #3b2a1a;
  --bege: #f1e5c8;
}

header {
  background-color: var(--marrom);
  color: var(--bege);
}

calc()

O que é: uma função que faz contas com medidas, até com unidades diferentes.

Para que serve: calcular tamanhos que dependem de dois valores, como "a largura toda menos 40 pixels".

Quando usar: quando um valor fixo e um relativo precisam andar juntos. Nas contas com mais e menos, os espaços em volta do sinal são obrigatórios.

Exemplo

.caixa {
  width: calc(100% - 40px);
}

:focus

O que é: uma pseudo-classe que vale quando o elemento está selecionado, como um campo onde o cursor está piscando.

Para que serve: mostrar ao visitante onde ele está, principalmente a quem navega só pelo teclado.

Quando usar: em campos de formulário, botões e links. Não esconda o contorno do foco sem colocar outro no lugar, porque isso prejudica a acessibilidade.

Exemplo

input:focus {
  border-color: #007BFF;
  outline: 2px solid #007BFF;
}

:nth-child()

O que é: uma pseudo-classe que escolhe um filho pela sua posição dentro do pai.

Para que serve: estilizar itens alternados ou específicos, como linhas pares de uma tabela.

Quando usar: o even pega os pares, o odd pega os ímpares, e um número escolhe aquela posição exata.

Exemplo

tr:nth-child(even) {
  background-color: #eee;
}

display: none e opacity

O que é: o display: none tira o elemento da página, como se ele não existisse. O opacity deixa o elemento transparente, de 0 (invisível) a 1 (normal).

Para que serve: esconder ou esmaecer elementos.

Quando usar: o display: none para o que não deve ocupar espaço, e o opacity para efeitos suaves, porque ele combina com a transition.

Exemplo

.escondido {
  display: none;
}

.fraco {
  opacity: 0.5;
}

Resultado

Este texto está com opacidade 0.4.

@keyframes e animation

O que é: o @keyframes descreve as etapas de uma animação, e o animation aplica essa animação a um elemento.

Para que serve: criar movimentos que acontecem sozinhos, sem precisar de um evento, como um elemento que pulsa.

Quando usar: para efeitos de destaque. Use com moderação, porque excesso de movimento cansa e atrapalha quem tem sensibilidade a movimento.

Exemplo

@keyframes pulsar {
  from { transform: scale(1); }
  to { transform: scale(1.1); }
}

.botao {
  animation: pulsar 1s infinite alternate;
}

object-fit

O que é: a propriedade que define como uma imagem se encaixa no espaço que tem, quando a proporção é diferente.

Para que serve: evitar que a imagem fique esticada ou achatada.

Quando usar: o cover preenche tudo e corta o que sobra, e o contain mostra a imagem inteira, deixando sobras.

Exemplo

img {
  width: 300px;
  height: 200px;
  object-fit: cover;
}
